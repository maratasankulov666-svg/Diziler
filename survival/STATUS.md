## Техника (проверено)
- **Ловушки:** не править .sh, пока он выполняется (bash читает файл по ходу и падает). Z-Image при «shopping mall» тянет в фото: помогает «flat 2D cartoon, cel shaded, bold ink outlines on everything». Генерация кадра ~7 мин, а при параллельном TTS ~15 мин; TTS 37 с текста ~45 мин при занятом CPU.
- **Видеокарты нет**: 4 CPU, ~15 ГБ RAM. Генерация на CPU.
- **Фоны**: `engine/background.py`.
  - SDXL-Turbo в bf16, ~25 с на кадр 1024×576.
  - В fp32 падает по памяти.
  - Людей SDXL-Turbo рисует плохо, поэтому только фоны без персонажей.
- **Герой**: `engine/stickman.py`, PIL, 8 поз, 5 лиц, режим силуэта.
- **Qwen3-TTS**: только в отдельном окружении `/home/user/.venvs/qwen`.
  - Пакет `qwen-tts` ломает основное `/opt/dizi-venv`: понижает transformers и huggingface-hub.
  - После установки в основное окружение нужно чинить так: `pip install "transformers>=5,<6" "huggingface-hub>=1.32,<2"`.
  - Модель `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`, ~25 с на фразу на CPU.
  - Годы словами («Year one») читает плохо, писать «Day three hundred».
- **Whisper**: faster-whisper в `/opt/dizi-venv`.
  - Путь к файлу не принимает (ошибка av). Подавать numpy-массив 16 кГц через librosa.
- **YouTube**:
  - видео скачать отсюда нельзя («Sign in to confirm you're not a bot»);
  - списки видео (yt-dlp `--flat-playlist`) и обложки i.ytimg.com работают.
- **vidIQ**: кредиты закончились.
- **Репозитории стилей**: `bash survival/tools/setup.sh` качает их в `survival/vendor/` (в git не попадает):
  - kaomei/stickman-video-director, стиль B4 Survival Thriller;
  - dsauce/stickman-kino;
  - sdxl_prompt_styler.
  - Запуск npm-кода из kaomei заблокировал классификатор безопасности.
