# DiziVizyon

Производство видео для YouTube-канала [@DiziiVizyon](https://youtube.com/@diziivizyon) о турецких сериалах.

- Начать работу в новой сессии Claude: написать **«дизи»**.
- Процесс: `.claude/skills/dizi/SKILL.md`. Состояние канала: `CHANNEL.md`. Разбор канала: `ANALYSIS.md`.
- Установка инструментов: `bash tools/setup.sh`.
- Готовые видео: `videos/` (720p-версии и Shorts можно скачать прямо с GitHub).
