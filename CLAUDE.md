# DiziVizyon — YouTube-канал о турецких сериалах

Пользователь общается по-русски, видео канала — на турецком. Он работает с телефона: всё делай сам и присылай готовые файлы.

**Если пользователь пишет «дизи» / «dizi» (или просит видео, Shorts, обложку для канала) — сразу запусти скилл `dizi`** (`.claude/skills/dizi/SKILL.md`): установи инструменты (`bash tools/setup.sh`), прочитай `CHANNEL.md` и спроси, какое видео делаем, предложив варианты.

Ключевые файлы:
- `CHANNEL.md` — состояние канала, что уже вышло, уроки, текущий сериал №1.
- `.claude/skills/dizi/SKILL.md` — полный процесс (факты → видео-источники → распознавание → сценарий → озвучка → монтаж → Shorts → обложка → публикация).
- `videos/build/` — конвейер сборки; `videos/voiceover.py` — озвучка VoxCPM2 с проверкой Whisper.
- `samples/channel_voice_announcer.wav` — голос канала (не менять без согласия).
- `assets/music/` — музыка Kevin MacLeod (CC BY, атрибуция в описании обязательна).

Правила: факты только из проверенных источников и распознанной речи серий; никаких перезаливов чужих видео целиком; кадры из сериалов короткими планами под голос ведущего; не ставить логотип TRT и не писать ложных «2. Fragmanı». После работы — коммит и пуш в рабочую ветку, обновить `CHANNEL.md` (таблица «Что вышло», уроки).
