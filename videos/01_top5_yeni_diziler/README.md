## Монтаж в CapCut

Таймкоды каждой фразы лежат в `timing.json` (поле `block`: intro, 5, 4, 3, 2, 1, graveyard, soon, outro).

1. **Интро (0:00–0:20):** быстрая нарезка по 1–2 секунды из всех пяти сериалов, крупно логотип DiziVizyon.
2. **Каждое место (№5 → №1):**
   - Большая плашка «5», «4»… и название сериала, 2–3 секунды.
   - Под рассказ о сюжете: **короткие** кадры из официального фрагмана, по 2–4 секунды, без оригинального звука, только под голос.
   - Под имена актёров: их фото с подписью.
   - Под шутку: стоп-кадр, лёгкий зум, звуковой эффект (ба-дум-тсс, смех) или мем-реакция.
3. **Кладбище сериалов:** тёмный фон, надгробия с названиями (можно нарисовать в CapCut), грустная музыка с юмором.
4. **Аутро:** вопрос к зрителям крупным текстом, конечная заставка со ссылкой на прошлое видео.
5. **Музыка:** только из библиотеки CapCut с пометкой «коммерческое использование» или из YouTube Audio Library.

> **Правило безопасности:** кадры из сериалов не дольше 3–4 секунд подряд, оригинальная дорожка фрагмана выключена. Голос ведущего должен звучать почти всё время. Так видео остаётся авторским обзором, а не перезаливом.
